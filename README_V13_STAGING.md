# AGRO BAROMETER V13 — накопичувальна збірка (НЕ ОПУБЛІКОВАНО)

Стан: 25.10.2026. Вихідна точка — локальна V12.1, яка **не** завантажувалась у GitHub після опублікованої V12. Нова версія містить чистий обчислювальний модуль `public/js/agro-economics-core-v13.mjs` та тести `scripts/economics-v13.test.mjs`. Вебінтерфейс V13 наразі не підключено, жодні нові показники на діючому сайті не змінилися.

## Узгоджена методика
- Відправна точка: центр Олександрії як свідомий орієнтир для кількох господарств.
- 6 культур: пшениця, кукурудза, соняшник, ячмінь, соя, ріпак.
- Пшениця різних класів: класи і специфікації — окремі групи порівняння.
- Самовивіз: витрати продавця на перевезення = 0 лише за підтвердження умов покупцем.
- Доставка: найманий зерновоз, базова місткість 25 т; ринкова ставка за тонну, часто з ПДВ.
- Точний термінал — пріоритет, місто — орієнтир і не підстава для остаточного застосування ставки на термінал.
- Господарство платник ПДВ. Для числового порівняння параметр `vat_rate` подається явно, а не вгадується; право на кредит не випливає автоматично з реєстрації.
- Завантаження власною технікою в обох варіантах, тому спільні витрати відокремлені від диференційних.
- Очікування зазвичай входить у тариф, але для сертифікації окремого запису умова має бути підтверджена.
- Якість попередня, остаточну перевіряє покупець; перерахунок за конкретним договором. Без підтверджених умов якості — список на перевірку.
- Відстрочка платежу припустима; різні умови оплати не змішуються в одну порівняльну групу без окремої моделі вартості грошей.
- Приватної бази покупців не створюємо.

## Обчислювальний модуль
- `evaluateV13(offers,rates,options)` — чиста функція без доступу до мережі та без змін на сайті.
- Виходи: `ranked`, `review`, `archived`, `summary`.
- Підтвердження тарифу: `validated_for_market_model===true` + `verified_document`, відповідність напряму, терміналу, культурі, ПДВ, 22–28 т, очікуванню, дата не старіша 14 діб, принаймні два незалежні джерела; якщо відносний розкид ставок перевищує 35% від медіани, потрібна ручна перевірка (цей поріг — консервативне внутрішнє правило, не ринковий стандарт).
- Ідентичність джерел спочатку `source_organization_id`/`carrier_id`, потім домен як консервативне запасне правило. Дві сторінки одного майданчика не рахуються за два незалежні джерела.
- Знайдений діапазон і медіана тарифів **не є ринковою котировкою** і не використовуються без документального підтвердження.
- Додаткові витрати мають бути явно підтверджені на нетто-основі; інакше блокування розрахунку.
- Жоден запис зі старої V11-бази сам не стане схваленим: поточний механізм імпорту задає `validated_for_market_model:false`.
- 11 барометрів, збирачі та публічна V12 не змінені.
