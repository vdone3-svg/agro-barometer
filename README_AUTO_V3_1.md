# AGRO BAROMETER Auto V3.1 — захист якості пунктів приймання

Це повний пакет заміни файлів для поточного GitHub репозиторію. Збережені Netlify Functions і HTML.

- Некоректні рядки, в яких поле пункту приймання містить текст сусідньої оферти/компанії/продукту, **пропускаються**. Це не підтверджує інші записи.
- HTML entity `&#x27;` у назвах міст декодується.
- Автоматичні пропозиції залишаються `verification: unverified`; не впливають на бали 0–100.
- Не запроваджує підтвердження ПДВ, базису або вартості доставки.

## Оновлення
Розпакуйте ZIP, завантажте внутрішні файли/папки в корінь GitHub репозиторію `vdone3-svg/agro-barometer` (без додаткової папки). Commit changes. Після публікації Netlify запустіть `collect-morning` через Run now, відкрийте `/.netlify/functions/public-indicators` та перевірте записи `offers`.

Публікація цього ZIP не є підтвердженням фактичної коректності всіх рядків E-ZERNO. Перевірте живу відповідь після деплою.
