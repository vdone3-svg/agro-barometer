# AGRO BAROMETER V13 — новинна аналітика (робочий модуль)

Новий головний блок «Що відбувається на аграрному ринку» для шести культур. Новини отримуються серверною функцією `news-digest` із трьох відкритих RSS Latifundist (зерно, переробка, елеватори), з датою, джерелом, посиланням і вікном свіжості 14 днів. Додається просте текстове зведення за кожною культурою, але не генерується висновок про ріст або падіння ціни без документованих котирувань. Якщо новин немає, система показує обмеження, а не вигадує ситуацію.

**Обмеження:** автоматичне завантаження й класифікація перевіряються на тестових RSS; зовнішній RSS не перевірено живим викликом із Netlify. Дозволеність/ліміти автоматичного отримання, доступність RSS та можливість роботи з копіями потрібно перевірити перед виробничим запуском. Новини не змінюють історичних 11 барометрів і не впливають на рейтинг покупців. Без API-ключів.

Новий код: `netlify/functions/_news_digest_v13.mjs`, `news-digest.mjs`, `public/js/agro-news-v13.mjs`, блок у `public/index.html`, `scripts/v13-news.test.mjs`.
