# AGRO BAROMETER Auto V10.1 — маршрути для кукурудзи

## Зміни

- Рені (Одеська обл.): 681 км, https://wayzi.net/distance/oleksandriia/
- Золочів (Львівська обл.): 709 км, https://wayzi.net/distance/oleksandriia/
- Ярмолинці (Хмельницька обл.): ~552 км, https://flagma.ua/uk/vidstan-yarmolincy-dnepropetrovsk/ — **оцінка за проміжною точкою маршруту**, не пряме вимірювання між центрами міст.
- «Переяславська» не ототожнюється автоматично з Переяславом.
- Усі попередні маршрути та логіка V10 збережені. Всього 8 маршрутів.

Ці маршрути — планові міжміські відстані. Тарифи та одиниця оголошених цін не підтверджені; будь-який залишок лише сценарний, без впливу на барометри.

## Установка

Розпакуйте ZIP; у GitHub (main) завантажте вміст через Add file → Upload files, замінивши наявні файли. Після Netlify Published оновіть сайт. Запускати collect-morning не потрібно.

## Перевірка

У «Кому вигідніше продати? — Auto V10.1» виберіть «Кукурудза» та введіть тестовий тариф 3 грн/(т·км). У таблиці мають з’явитися **ExpoGrain · Рені**, **VVT Group · Ярмолинці**, **ТОВ Коудайс Україна · Золочів** (за умови що оголошення досі наявні в API і не архівні). НІБУЛОН · Переяславська має залишитися без маршруту.

Тестові умовні залишки при припущенні грн/т: ExpoGrain 7200−681×3=5157, VVT 5800−552×3=4144, Коудайс 6000−709×3=3873 грн/т. **Це НЕ реальні чисті ціни та не рекомендації продажу.**
