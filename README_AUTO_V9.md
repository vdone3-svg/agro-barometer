# AGRO BAROMETER — Auto V9: Кому вигідніше продати?

## Новий блок
На головній сторінці після V8 з’явиться **«Кому вигідніше продати? — Auto V9»**.

1. Оберіть конкретний продукт і клас зерна.
2. Введіть відомий тариф **грн/(т·км)**. За замовчуванням тариф порожній.
3. Система автоматично порівняє всі непідтверджені гривневі пропозиції до 30 днів, для яких у каталозі є маршрути між містами.
4. Відобразить сценарні витрати, умовний залишок, кількість відсутніх маршрутів, і поріг рівності тарифу для двох кращих сценаріїв за наявності двох маршрутних пропозицій.

## Поточні обмеження
- У каталозі V8 поки **лише Олександрія → Ізмаїл 648 км**. Порівняння з іншими містами буде **недоступне**, доки не додано перевірені відстані. Це не помилка.
- **Немає автоматичного транспортного тарифу**; тариф вводить користувач. Сценарій, а не ринкова рекомендація.
- Невідомі ПДВ, базис, одиниця ціни. Порівняння робиться виключно за *умовою* грн/т, однакового ПДВ і базису, продавець сплачує доставку. Результати **не є чистими цінами**.
- Рахуємо лише точний збіг продукту/класу й валюти UAH; USD не перемішуємо.
- Історію Netlify Blobs, API збирання й незалежні барометри 0–100 не змінено.
- Якщо є лише одна розрахована пропозиція — **немає висновку про найвигідніше місто**.

## Встановлення
1. Розпакуйте ZIP.
2. У GitHub репозиторії `vdone3-svg/agro-barometer` завантажте **вміст** архіву до кореня `main` (`Add file` → `Upload files` → `Commit changes`). Перевірте, що папки `public/`, `netlify/`, `scripts/` збереглися.
3. Дочекайтеся Netlify Deploy `Published` і оновіть сторінку, за потреби Ctrl+Shift+R.
4. Знайдіть розділ «Кому вигідніше продати? — Auto V9» нижче V8.
5. Оберіть `Пшениця 2 клас`, введіть **лише для тесту** `3` грн/(т·км). РАМБУРС · Ізмаїл (8300 грн) → 648×3=1944 грн/т; залишок 6356 грн/т. Якщо є інші ізмаїльські пропозиції на пшеницю 2 класу, вони також з’являться.
6. Переконайтеся, що система прямо повідомляє про відсутні маршрути і не називає цей результат підтвердженим рішенням.

**Не вводьте вигаданий тариф як реальний тариф господарства.**
