# AGRO BAROMETER V13 — наповнення бази ринкових даних

## Впроваджено в робочій збірці

- `collect-market-archive.mjs`: щоденна Netlify Scheduled Function (05:20 UTC), зчитує конфігуровані RSS, не обходить сайти поза дозволеними каналами.
- `_market_archive_v13.mjs`: парсинг та облік походження кожного посилання, дедуплікація за URL, видалення матеріалів старше 120 днів, максимум 3500 статей, журнал останніх 300 перевірок каналів.
- `market-data-coverage.mjs`: публічний read-only API `/.netlify/functions/market-data-coverage`, який показує лише стан наповнення та помилки RSS.
- Жодне архівне повідомлення **не вважається підтвердженим фактом**, а кількість новин **не є доказом напряму ціни**.

## Наступні незалежні числові канали — не позначати підключеними

1. USDA FAS PSD (виробництво, використання, запаси, імпорт/експорт): офіційний API https://apps.fas.usda.gov/opendataweb/home, потребує індивідуального ключа api.data.gov і перевірки кодів культур/країн/маркетингових років.
2. Єврокомісія Agri-food Data API: https://agridata.ec.europa.eu/extensions/API_Documentation/cereals.html; потрібне точне зіставлення endpoint, одиниць, stage і країн. Це ЄС, не закупівельна ціна Олександрії.
3. World Bank Pink Sheet: https://www.worldbank.org/en/research/commodity-markets, офіційні USD котирування; потрібні валідація назв серій і дата оновлення. Не підміняти насіння соняшнику соняшниковою олією.
4. Ціни українських покупців: лише підтверджені ПДВ, базис, якість і одиниця можуть входити до рейтингу.
5. Наймані зерновози: для рейтингу потрібні свіжі перевірені ставки відповідного маршруту, а не медіа-орієнтир.

## Валідація перед випуском

`npm test`; потім перевірка `/.netlify/functions/market-data-coverage` після першого Netlify Scheduled Function; окремо — живий моніторинг статусу всіх RSS.

Це накопичувальна збірка, НЕ публікувати окремо. 11 барометрів не змінюються.
