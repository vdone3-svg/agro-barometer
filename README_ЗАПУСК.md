# AGRO BAROMETER — Netlify Auto v1

## Що справді автоматизовано
- Netlify Scheduled Functions (Git-deploy) збирають **тільки офіційний курс НБУ USD/EUR**; це технічний перший працюючий канал.
- Щоранку о **04:35 UTC** (06:35 Київ узимку, 07:35 влітку), а також о 10:00 та 14:00 UTC. В обох сезонах ранковий запуск відбувається **до 08:00 Europe/Kyiv**. Netlify cron використовує UTC.
- Дані пишуться в **Netlify Blobs** (спільні між деплоями). Сторінка читає `/.netlify/functions/market-status` при відкритті та кожні п'ять хвилин, якщо відкрита.
- Помилка джерела не переписує останнє успішне значення, час даних не підміняється часом перевірки.
- **Ціни культур, пального, добрив і новини поки історичні**: їхні автоматичні імпортери ще не створено. Курс НБУ не використовується як бал культури.
- Авторизації ще немає. Це **публічна** тестова версія: не завантажуйте приватні прайси й контакти.

## Як увімкнути (без програмування після першого підключення)
1. Створіть порожній **приватний репозиторій** на GitHub (можна через вебінтерфейс).
2. Розпакуйте цей ZIP і завантажте **вміст кореня** до репозиторію: `public/`, `netlify/`, `netlify.toml`, `package.json` та інші файли. `index.html` знаходиться у `public/`.
3. У Netlify відкрийте **існуючий** сайт `startling-cactus-baf5c4` → **Project configuration / Build & deploy** → **Link repository / Connect to Git** (назви меню можуть змінюватися). Підключіть цей репозиторій до того ж сайту, щоб зберегти URL. Не створюйте новий сайт, якщо хочете стару адресу.
4. Налаштування збірки: **Publish directory: `public`**; Build command можна залишити порожнім; `npm install` відбудеться автоматично, коли Netlify розпізнає `package.json`.
5. Після production deploy відкрийте Netlify → Functions: мають з'явитися `collect-morning`, `collect-daytime` (позначені Scheduled) та `market-status`.
6. У Netlify → Functions → `collect-morning` → **Run now** для першої перевірки. Перегляньте Logs (має бути `status ok` або опис помилки).
7. Відкрийте `https://startling-cactus-baf5c4.netlify.app/.netlify/functions/market-status`. Очікується `status:"ok"`, поля USD/EUR та дата оновлення. На головній сторінці з'являться курси.

## Якщо щось не запрацює
- `404 /market-status`: functions не задеплоєні; перевірте Git-deploy, папку `netlify/functions`, налаштування.
- `not_started`: scheduled function ще не запускали; натисніть Run now.
- `failed / errors`: подивіться Functions Logs; можлива недоступність API НБУ.
- Відсутність live зернових цін — очікувана поведінка цієї версії, а не помилка.

## Архітектура для наступного етапу
Підключати наступні імпортери по одному: офіційні відкриті API, далі машиночитані індикативи зерна/пального за погодженими умовами. Комерційні приватні пропозиції тільки після впровадження захищеного входу й перевірки підстав для використання.

## Важливо про права доступу
Netlify Blobs не надає ролей користувачів самостійно. Для закритого сайту буде потрібна авторизація та контроль доступу на сервері. Не покладайтеся на невідоме посилання або лише пароль у JavaScript.
