# AGRO BAROMETER — Auto V12: економічний фільтр

## Встановлення
1. Розпакуйте архів. Завантажте **вміст** архіву в корінь GitHub `vdone3-svg/agro-barometer` через Add file → Upload files.
2. Commit до main. Netlify опублікує сайт автоматично.
3. На головній сторінці знайдіть «Auto V12 — Економічний фільтр покупців». Run now не потрібен.

## Безпека висновків
Поки `approved_for_automatic_pricing=0` та оголошення `unverified`, рейтинг буде порожнім — це правильно. Пропозиції не приховуються як «невигідні» через відсутність даних.
Алгоритм перевіряє місто, дату, підтверджену одиницю закупівельної ціни, клас, ПДВ, базис, напрямок, дві незалежні свіжі документовані транспортні ставки, схвалення тарифів. Додатковий фільтр «невигідно» не активується до калібрування похибки.

## Обмеження
Ця версія НЕ підключає зовнішній маршрутизатор і не вигадує кілометраж поза каталогом V10.1. НЕ виконує вебскрейпінг DELLA/DeGruz/Transportica. НЕ затверджує ставки автоматично. Стара форма внесення тарифів і 11 барометрів залишені без змін.

## Перевірка
`npm test` — тести моделі та наявні тести проєкту.
