# AGRO BAROMETER Auto V5 — динаміка непідтверджених пропозицій

## Що змінилося
- На головній сторінці доданий вибір категорії / компанії / товару та перегляд усіх доступних спостережень вибраної ставки.
- Лінійний графік виникає лише після появи щонайменше двох **різних дат оголошень** тієї самої пропозиції; поки є одна — показана початкова точка без вигаданої зміни.
- Порівняння відбувається у вихідній валюті, за незмінною ідентичністю пропозиції (компанія/товар/формула/валюта/регіон/пункт/джерело).
- Джерелом є існуючий API `/.netlify/functions/offer-history`. Netlify Blobs і розклад не змінені.
- Всі значення непідтверджені. Невідомі одиниці вимірювання, ПДВ, базис; не враховується доставка з Олександрії; 11 барометрів не змінюються.

## Встановлення
1. Розпакувати ZIP і завантажити **вміст**, а не ZIP як файл, до кореня існуючого репозиторію GitHub `vdone3-svg/agro-barometer`, зберігши папки `public/js`, `netlify/functions`, `scripts`.
2. Commit changes у гілку `main`, дочекатися успішного Netlify Deploy.
3. Відкрити головну сторінку, прокрутити до «Динаміка пропозицій — Auto V5» і вибрати товар.
4. За поточних 7 спостережень для кожної пропозиції очікується одна точка й напис «Є тільки одне спостереження». Це **правильний результат**.
5. Перевірити `/.netlify/functions/offer-history`: кількість спостережень повинна залишитися 7, якщо джерело не оновилося. Run now для V5 не потрібен.

## Межі
- API видає останні 300 спостережень; графіки охоплюють лише ці доступні дані.
- В архіві є обмеження 3000 записів; це не резервна копія і не довгострокова БД.
- V5 — лише зміни інтерфейсу, історія не перезаписується.
- Не додавайте приватні ставки: сайт залишається публічним, доки не впроваджено авторизацію.
