# V13 — перевірка чистоти офіційних даних USDA

## Що змінили

- Дані з відповіді USDA не приписуються іншій культурі, якщо є код товару і він відрізняється від запитаного.
- Показники України і світу перевіряються окремо; за відмінності географічного коду рядок відхиляється.
- Некоректні рядки враховуються у звіті відхилень без підстановки вигаданих значень.
- Всі зміни перевіряються автоматичними тестами (`npm test`).

## Ще не перевірено

Живий USDA API із ключем у Netlify. До фактичного розгортання і успішного виконання збирача в базі не виникнуть нові записи. `USDA_API_KEY` уже налаштований користувачем у Netlify, **секрет не зберігається в коді**.

## Інтеграційна перевірка після розгортання

1. `/.netlify/functions/usda-psd-status` — стан джерела.
2. `/.netlify/functions/market-numeric-coverage` — кількість записів для шести культур.
3. Успіхом вважаємо фактичні ненульові записи з коректними кодами, одиницями, scope і датами. Не лише `status=ok`.

**GitHub і Netlify в цьому етапі не змінювались.**
