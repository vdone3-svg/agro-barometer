# V13 — багатоджерельна аграрна аналітика (робоча збірка)

## Що реалізовано
- Каталог українських і міжнародних джерел; `netlify/functions/_news_sources_v13.mjs`.
- RSS-модуль підтримує декілька незалежних видавців, окрім Latifundist: додано **AgroPortal** (`https://agroportal.ua/en/rss/type_news`).
- Відмовостійкий збір: помилка джерела не вимикає інші; кожне джерело має `ok` та лічильник.
- Дедуплікація однакових заголовків із різних видань; окремий лічильник незалежних доменів.
- Позначення 14-денного вікна, посилання на першоджерело; немає вигаданої зміни ціни.

## Важливі обмеження
- Канали RSS вписано в конфігурацію, але **живий Netlify-запит до них ще не протестований**. Навіть наявність RSS не означає дозволу на копіювання повних статей. Беремо лише заголовок, короткий анонс для класифікації, посилання й дату; публічний блок показує заголовки та оригінальні посилання.
- Каталог — не список активних підключень. `integration_pending` / `licence_or_feed_required` означають, що API/RSS/умови використання ще не перевірено; код їх не парсить.
- Наявний текстовий висновок **лише тематичний огляд заголовків**, а не фактологічний синтез змісту публікацій. Для фактологічних висновків потрібно окреме вилучення перевірених фактів із дозволених текстів і відповідні цитування.
- Джерела офіційної статистики мають іншу періодичність; не повинні зникати лише через 14-денний фільтр новин. Це наступний окремий модуль.
- Не оновлювати GitHub до інтеграційної перевірки.
