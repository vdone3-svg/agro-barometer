# AGRO BAROMETER V13 — перші реальні показники (25.10.2026)

Новий `/.netlify/functions/verified-market-facts` віддає **датовані довідкові записи**, не отримані безпосередньо із живих API Netlify. Кожен запис містить джерело, дату публікації, дату спостереження, культуру, метрику, одиницю і статус перевірки.

**Офіційне першоджерело — Держстат України:** оприлюднено 20.10.2026, дані станом на 01.10.2026: зернові та зернобобові 36,3 млн т; пшениця 26,1 млн т; річна зміна проти аналогічної дати відповідно +9,7% і +11,8%. https://stat.gov.ua/uk/news/nove-na-sayti-ploshchi-valovi-zbory-ta-urozhaynist-silskohospodarskykh-kultur-1

**Другорядний переказ балансу USDA:** GrainsPrices, October 2026, оцінка кінцевих світових запасів 2026/27: кукурудза 280,440 млн т, пшениця 276,038 млн т, соя 124,278 млн т. https://grainsprices.com/usda . Ці записи мають статус `secondary_needs_official_crosscheck` і не повинні видаватися за пряме отримання з USDA API.

Цей пакет **не змінює 11 барометрів**, не створює котирувань покупців, не призначає сигнал купувати/продавати. Він додає перевірені з вебпублікацій довідкові знімки для подальшого звірення з живими API.
