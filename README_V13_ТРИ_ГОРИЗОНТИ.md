# V13 — три часові горизонти ринкової оцінки

Узгоджені окремі горизонти: 7–14 днів, 30 днів, 3 місяці (робоча технічна межа 31–90 днів).

Реалізовано `public/js/agro-horizons-v13.mjs`. Новинний факт повинен мати `horizon`, `factor`, `metric`, `event_date`, `evidence_type`, `direction_basis`, `publisher`, `url`, `description`, `confirmed`, `crop` та `impact`.

Кожний горизонт отримує окремий висновок. Дані одного горизонту не переносяться автоматично на інший. Протилежні факти показуються як конфлікт, передруки однієї первинної публікації не вважаються незалежними джерелами.

Історія цін за 5 років лишається інформаційним графіком. 11 діючих барометрів 0–100 не змінюються. Числовий новий сигнал і автоматичні «купувати/продавати» заблоковані до калібрування моделі на фактичних даних і незалежній перевірці.

Це локальна робоча збірка, НЕ для розгортання: зовнішні потоки структурованих фактів ще не підключені до цього модуля.
