# AGRO BAROMETER — автоматичні ринкові індикативи V2

## Що додано

- `netlify/functions/_public_sources.mjs` — три перевірки джерел: каталог зернових E-ZERNO, каталог добрив E-ZERNO, таблиця гуртових цін пального Enkorr.
- `netlify/functions/public-indicators.mjs` — API останнього результату зі сховища Netlify Blobs.
- `collect-morning.mjs` і `collect-daytime.mjs` тепер запускають перевірку індикативів після збору НБУ. Помилка одного джерела не має скасовувати дані НБУ.
- `public/index.html` відображає окрему панель з датою джерела і станом імпорту; не змінює барометри 0–100.

## Публікація в існуючий Netlify

1. Розпакуйте ZIP.
2. У GitHub-репозиторії `vdone3-svg/agro-barometer` замініть `public/index.html`, `netlify/functions/collect-morning.mjs`, `netlify/functions/collect-daytime.mjs` та додайте два нових файли: `_public_sources.mjs`, `public-indicators.mjs` (усі шляхи з ZIP).
3. Commit changes у main. Перевірте наявність нового Published deploy на наявному Netlify-сайті (нового сайту не створюйте).
4. Netlify → Cloud compute → Functions → `collect-morning` → Run now.
5. Перевірте `/.netlify/functions/market-status` — НБУ повинен лишитися робочим; та `/.netlify/functions/public-indicators` — повинен бути список 3 джерел.
6. На головній сторінці внизу з'явиться панель автоматичних ринкових індикативів.

## Обмеження, які принципово збережені

- E-ZERNO: **лише моніторинг датованих оголошень**; ставки культур і добрив не потрапляють до числових барометрів. Автоматичний парсер ще не може надійно відокремити клас, населений пункт, ПДВ, базис і дату оферти.
- Enkorr: **тільки загальноукраїнські гуртові довідкові ціни** у грн/л із явно зазначеною датою таблиці. Це не ціна доставки до Олександрії.
- Якщо сайт змінив верстку, повернув 403 або немає дати, джерело позначається `error`. Попередні успішні дані зберігаються разом із первісною датою і не видаються за нові.
- Не передавати приватні комерційні дані в публічні Netlify Blobs чи HTML. Вхід співробітників ще не налаштовано.
- Сайт потребує інтернету, а автоматичне отримання виконується Netlify, не браузером користувача.

## Наступні кроки

Завершити валідацію окремих конкретних ставок із офіційних сторінок покупців, перевірити умови доступу агрегаторів і побудувати захищену приватну базу оферт із відповідними датами, ПДВ, логістикою та базисом.
