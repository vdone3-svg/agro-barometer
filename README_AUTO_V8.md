# AGRO BAROMETER — Auto V8: міська логістика

## Встановлення
1. Розпакуйте архів. У GitHub `vdone3-svg/agro-barometer` → `main` → Add file → Upload files завантажте **вміст** архіву зі збереженням папок `public/`, `netlify/`, `scripts/`.
2. Commit changes; перевірте успішний Netlify Deploy. Збір `collect-morning` повторювати не потрібно.
3. На головній сторінці прокрутіть до «🚚 Логістика від Олександрії — Auto V8». Виберіть «Пшениця 3 клас», потім «РАМБУРС · Ізмаїл». Система має показати місто **Ізмаїл**, підставити **648 км**, залишити тариф порожнім.
4. Для арифметичного тесту введіть **3 грн/т·км**: умовна доставка = **1944 грн/т**, залишок за припущенням грн/т = **6256 грн/т** при оголошенні 8200. **3 грн/т·км — навчальне число, не ринковий тариф.**
5. Виберіть інше місто: якщо маршруту в каталозі немає, км мають залишитися порожніми, їх можна ввести вручну.

## Обмеження
- Автоматичний маршрут наразі **лише Олександрія → Ізмаїл (648 км)**, географічна відстань між містами для планування, не до конкретної адреси. Джерело: https://flagma.ua/uk/vidstan-aleksandriyaukr-izmail/ . Альтернативні автомобільні варіанти 621/633 км.
- Місто з пункту визначається тільки за обмеженим списком однозначних назв; назви елеваторів чи заводів не геокодуються навмання.
- Тарифи не завантажуються автоматично. Жоден тариф зворотного напрямку не підставляється.
- Всі ставки E-ZERNO — непідтверджені, одиниця оголошення, ПДВ, базис невідомі. Результат лише сценарний, не рекомендація покупця.
- Барометри 0–100 не змінені; історія Netlify Blobs не видаляється.
