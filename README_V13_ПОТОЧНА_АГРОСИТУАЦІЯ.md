# V13 — Поточна агроситуація визначає рішення

Прийняте правило: п’ятирічні графіки виключно довідкові. Жоден сезонний шаблон або історична крива не може підвищити/знизити показник рішення чи спричинити рекомендацію «продавати/купувати». Наявні 11 історичних барометрів 0–100 залишаються без змін; підпис має явно казати, що це історична оцінка, а не сьогоднішній торговий сигнал.

Додано незалежний pure JS модуль `public/js/agro-current-evidence-v13.mjs` для структурованих актуальних фактів: український врожай, світові баланси, експортний попит, внутрішня переробка, логістика, місцеві ціни. Модуль відхиляє майбутні/несправжні календарні дати, несвіжі дані, неперевірені матеріали, чужу культуру, відсутні HTTPS-посилання й не бере повторні публікації одного видавця за незалежні підтвердження.

Поточний механізм вимагає достатніх незалежних фактів за трьома чинниками, включно з логістикою й актуальною ціною, і не видає бали 0–100 з новин. Він не підключений як автоматичний числовий сигнал до головного екрана: джерела ще не постачають уніфіковані перевірені записи. Якщо факти відсутні, відповідь «Потребує даних». Числову шкалу поточного рішення треба калібрувати на реальних даних і тестувати на історії, без самопроголошених порогів.

Дані для майбутньої інтеграції: USDA WASDE (щомісячні світові баланси), EU Agri-food Data Portal (ціни, виробництво, експорт, API), FAO/AMIS (зернові, соя), перевірені українські ціни та експортна статистика, логістика зерновозів. Застосовувати лише дозволені канали API/RSS/завантажень; не приписувати всім джерелам статус активного підключення.

**Стан:** робочий пакет, не розгортати без тесту на Netlify.
