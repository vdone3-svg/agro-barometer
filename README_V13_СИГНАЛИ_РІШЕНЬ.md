# V13 — Новини і рішення за барометрами

Користувач визначив: система повинна не тільки читати багатоджерельні новини, але й давати зрозумілий сигнал купувати / продавати / зачекати із числовим обґрунтуванням.

**Реалізовано без зміни старої формули:** окремий блок на головному екрані інтерпретує історичні барометри за 6 культурами, показує число тільки коли наявна базова історична оцінка, інакше `— / 100`. Пороги 35/65 — умовні редакційні пороги, а не прогнозна калібрована модель. Шкали зберігають своє значення 12-місячного цінового процентиля; статті RSS не додають до бала уявні пункти.

Новини поки окремий контекст. Наступний етап: перевірена структуризація показників із першоджерел, кількісна оцінка тренду та позавибіркова валідація, після якої можливий другий власне прогностичний індикатор. В жодному разі не видавати ймовірність чи ціну без валідації.

Не публікувати зараз: накопичувальна збірка, не перевірена на Netlify.
