# AGRO BAROMETER Auto V11.1 — захищене ручне внесення транспортних ставок

## Що нового
- Окрема сторінка `https://startling-cactus-baf5c4.netlify.app/admin-freight.html` з українською формою для **одного реального запису**.
- Запис іде `POST /.netlify/functions/freight-rates` з `Authorization: Bearer <FREIGHT_ADMIN_TOKEN>`; V11 API не змінювали.
- Токен вводиться при кожному збереженні та очищається з поля одразу. Він **не** міститься у GitHub, URL, JSON тілі запиту, localStorage або sessionStorage.
- Окрема сторінка не є приватною авторизацією: будь-хто може відкрити форму, але сервер має відхиляти POST без правильного токена. Користуватися тільки через HTTPS на довіреному пристрої.
- GET показує тільки лічильники і записи без секретів; ставки залишаються `validated_for_market_model:false`.
- Автоматичного збору з DELLA, DeGruz, Transportica немає. Заборонено вносити умовні сценарні тарифи як справжні.

## Встановлення
1. Розпакувати ZIP та завантажити **вміст** у корінь `main` репозиторію, замінивши наявні файли.
2. Дочекатися Netlify `Published`.
3. Відкрити `/admin-freight.html` і перевірити, що з'явилася форма, а лічильник — 0 (якщо ще немає записів).
4. **Не вводити токен і не зберігати жодних тестових ставок.** Реальний запис додавати тільки коли є джерело, дата, напрямок та фактична ставка.
5. Токен `FREIGHT_ADMIN_TOKEN` має бути налаштований у Netlify (24+ символи). Не надсилати токен у чат.

## Перевірка захисту
Форма у браузері не може підтвердити відмову неавторизованого POST без надсилання запиту. Серверний код V11 спершу перевіряє змінну середовища та точний `Bearer` токен і при невірному повертає `401 unauthorized`. Рекомендується окремо перевірити негативний сценарій, **не створюючи записів**, наприклад тестовим POST із завідомо неправильним токеном до API (має бути 401).

## Важливі обмеження
- Сайт публічний; це форма **захищеного запису**, а не повністю приватна адмін-панель.
- Збережені записи публікуються через GET API. Не внось персональні телефони/комерційні секрети в поля.
- Навіть документована ставка не переходить автоматично до рейтингу. Спершу потрібна методологія зіставлення напрямків, дат, ПДВ та розміру партії.
- Старі дані і 11 барометрів не змінюються.
