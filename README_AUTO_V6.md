# AGRO BAROMETER Auto V6 — п'ять культур

Встановлення: розпакувати ZIP, завантажити його внутрішні файли й папки в корінь GitHub `vdone3-svg/agro-barometer` із заміною старих, зробити commit у `main` та дочекатися Published у вже наявному Netlify-сайті. Не створювати новий сайт.

Що змінилося:
- Оновлено `_offers.mjs`: чіткіше відокремлення карток E-ZERNO за датами; дати «сьогодні/вчора» не використовуються; підтримка соняшника, кукурудзи, пшениці, ячменю й ріпаку. Складні/неоднозначні рядки як і раніше пропускаються.
- Додано `_crop_coverage.mjs`, поле `sources[grain].data.crop_coverage` з кількістю непрoверених оголошень для кожної культури.
- Додано фільтр культур і блок покриття на головну сторінку.
- Історія V4, графіки V5, НБУ та Enkorr залишені.

Перший тест: Netlify → Cloud compute → Functions → collect-morning → Run now. Далі перевірити `https://startling-cactus-baf5c4.netlify.app/.netlify/functions/public-indicators`: має з'явитися `crop_coverage`, а в `offers` — тільки знайдені однозначні кандидатні оголошення. Перевірити `offer-history`, що продовжує зберігати записи.

Важливо: це **не перевірені закупівельні ціни**. Одиниці, ПДВ, базис і доставка до Олександрії невідомі, багато пропозицій можуть бути старими. Ці записи не змінюють жодного з 11 балів 0–100. Для деяких культур `crop_coverage` може залишатися 0: це чесна відсутність даних, а не помилка розкладу. Рекомендовано вручну перевірити зіставлення компанії/товару/ціни/пункту у перших нових записах.

Локальні перевірки: `npm test` (19 тестів).
