# AGRO BAROMETER Auto V4 — історія пропозицій

## Встановлення
1. Розпакуйте архів. Завантажте **вміст** папки в корінь GitHub репозиторію `vdone3-svg/agro-barometer` (не вкладеною папкою).
2. Підтвердіть зміни у `main`; зачекайте на успішний deploy Netlify.
3. Netlify → Cloud compute → Functions → `collect-morning` → `Run now`.
4. Відкрийте `/.netlify/functions/offer-history` — має бути `status: ok` і `total_observations > 0`, якщо E-ZERNO повернув пропозиції.
5. На головній сторінці внизу з'явиться «Історія непідтверджених пропозицій».

## Гарантії / обмеження
- Перший збір V4 **не відновлює** історію до встановлення V4; лише поточний знімок, отриманий після першого запуску.
- Ключ пропозиції: товар + постачальник + пункт + валюта + інші ідентифікатори; той самий товар у іншого постачальника не зливається.
- Однакова ціна з тією самою датою ставки повторно не записується; зміна ціни або дати ставки дає нове спостереження.
- `quote_date` = дата, вказана джерелом, `first_seen_at` = час першого виявлення системою.
- `changes` — зміни оголошень, а не підтверджені зміни порівнюваних ринкових цін. ПДВ, одиниці та базис часто невідомі.
- Цей простий JSON-архів обмежений останніми **3000** спостереженнями і не є транзакційною базою: паралельні збирачі можуть конфліктувати. Для довгострокової масштабованої історії потрібне сховище з атомарним записом або журнал подій.
- Порожній журнал змін після першого запуску нормальний; `total_observations` має збільшитися.
- Співробітники не редагують дані. Всі 11 барометрів 0–100 залишаються без змін.
- Сайт досі публічний; не завантажуйте приватні комерційні ставки без авторизації.
