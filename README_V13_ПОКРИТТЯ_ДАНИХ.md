# V13: контроль покриття числових даних

Новий публічний endpoint: `/.netlify/functions/market-numeric-coverage`. Збирає показники наявності з двох Netlify Blobs (USDA PSD та EU DG AGRI), не публікує секретів та не обчислює сигнал продажу.

По кожній із шести культур показує кількість валідних записів світових/українських балансів за маркетинговими роками та цінових спостережень ЄС, дату останнього періоду, географію й статус джерел.

Це **не готовий рейтинг**: відсутні підтверджені закупівельні ціни саме для України та перевезення з Олександрії; USDA/ЄС — лише контекст. Реальна працездатність API не підтверджена без розгортання та ключа USDA.

Не встановлювати як окремий проміжний реліз: використати при фінальному V13.
