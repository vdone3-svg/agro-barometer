# AGRO BAROMETER Auto V12.1 — автоматичні міжміські маршрути

1. Завантажити вміст ZIP у корінь GitHub `vdone3-svg/agro-barometer` (гілка main). Netlify опублікує сайт.
2. Без додаткових дій V12.1 показуватиме міста та реальний стан тарифної бази, **але не вигадуватиме кілометри**.
3. Щоб активувати маршрутизатор, зареєструвати власний ключ GraphHopper Directions API на graphhopper.com, додати у Netlify → Environment variables → `GRAPHHOPPER_API_KEY`, Scope: Functions/All, Production. Зробити новий Deploy. Не публікувати ключ у GitHub чи чаті. Враховувати ліміти/тарифи провайдера.
4. Відкрити сайт та розділ `Auto V12.1`, вибрати однозначне місто й натиснути `Розрахувати маршрут`. Тестовий API: `/.netlify/functions/logistics-route?city=Ізмаїл&region=Одеська%20обл.`
5. Результат GraphHopper — планова відстань між містами для профілю `car`; **це не маршрут важкого зерновоза** і не ціна перевезення. Геокодування може повернути `ambiguous_location`, тоді відстань НЕ підставляється. Транспортні ставки залишаються в окремій базі та не отримують автоматичного схвалення.

**Зміни:** Додано API `/logistics-route`, службову перевірку геокодування, панель V12.1 та тести. Збір цін, історія, форма тарифів, захист FREIGHT_ADMIN_TOKEN і всі 11 барометрів без змін. Зовнішніх API без ключа не викликаємо; DELLA/DeGruz/Transportica не скрейпимо.

`npm test` — локальні тести.
