## Як встановити
Розпакувати ZIP, завантажити його вміст в корінь GitHub-репозиторію `vdone3-svg/agro-barometer` гілка `main` через Add file → Upload files; замінити файли і Commit changes. Дочекатися Netlify Published. Повторний запуск збору не потрібний.

## Як перевірити
1. Відкрити `https://startling-cactus-baf5c4.netlify.app/data/logistics-city-routes-v8.json` і знайти `"version": "city_v10"`, 5 міст.
2. На головній сторінці знайти «Кому вигідніше продати? — Auto V10».
3. Вибрати «Пшениця 3 клас» і ввести **тільки тестовий** тариф 3 грн/(т·км). Для РАМБУРС, Ізмаїл: 8200 - 648×3 = 6256 (тільки за припущення, що оголошена ціна — грн/т, і доставку оплачує продавець).
4. Для деяких товарів з’являться покупці з Одеси, Києва та інших міст; підсумок лишається сценарним.
