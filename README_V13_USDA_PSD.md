# USDA PSD — накопичувальний модуль V13

Документація: https://apps.fas.usda.gov/opendataweb/home та https://apps.fas.usda.gov/opendata/swagger/ui/index

Серверний ключ: `USDA_API_KEY` (Netlify Environment variables). **Не публікувати в GitHub і не надсилати в чат.**

- `collect-usda-psd.mjs`: щовівторка запитує каталог USDA і баланси за 2 маркетингові роки; помилки окремих культур не руйнують інші результати.
- `usda-psd-status.mjs`: публічний стан, кількість записів і назви культур, без ключа.
- Зберігає світові й українські баланси відокремлено, оригінальні одиниці та атрибути.
- Не змінює 11 барометрів, не видає прогнози продажу та не прирівнює баланси до закупівельних цін.
- Live API не перевірено: ключа ще немає. Інтеграцію слід перевірити в Netlify перед використанням у виробничому аналізі.
- Код України визначається динамічно через USDA `/countries`, без припущення про ISO-код. Якщо у каталозі немає України, українські записи пропускаються з окремим повідомленням.
