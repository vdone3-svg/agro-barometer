# AGRO BAROMETER — Netlify Edition

## Швидка публікація (без програмування)
1. Розпакуйте ZIP.
2. У Netlify відкрийте https://app.netlify.com/drop .
3. Перетягніть **тільки папку `public`**, а не весь ZIP.
4. Отримаєте постійну адресу `*.netlify.app` (назву можна змінити в Netlify).
5. Перевірте сайт з телефону.

**Увага:** цей варіант розгортає лише статичний сайт. Він **не запускає автоматичний збір**, не створює логіни співробітників і **не захищений паролем**. Посилання на сайт може відкрити стороння особа. Не публікуйте приватні дані, доки не налаштована авторизація.

## Оновлення даних для всіх телефонів
- Єдиний спільний файл: `public/data/market.json`.
- При відкритті сторінки, поверненні до вкладки та кожні 5 хвилин під час перегляду браузер перевіряє цей JSON.
- Щоб змінити дані: оновіть `market.json`, розмістіть нову версію `public` в Netlify (або застосуйте Git-деплой). Усі побачать її за тією самою адресою.
- Старі котирування не стають поточними від повторного завантаження сторінки.

## Коли підключатимемо справді автоматичний збір
1. Створити Git-репозиторій із цим проєктом та приєднати до Netlify з publish directory `public`. Це потрібно для зручного оновлення коду й функцій.
2. Створити Supabase (PostgreSQL): tables `sources`, `quotes`, `news`, `import_batches`, `audit_log`, `users`.
3. Налаштувати авторизацію: лише адміністратор додає дані, співробітники — тільки читають. Вимкнути публічний доступ і забезпечити Row Level Security.
4. Налаштувати серверні імпортери лише для дозволених машинозчитуваних API. Дані Telegram/прайси — через перевірений адмін-імпорт.
5. Щоденне завдання до 08:00 Europe/Kyiv; cron Netlify задається за UTC, тому враховувати перехід DST (найпростіше запускати о 05:00 UTC цілий рік і контролювати локальний час, що означає 07:00 взимку / 08:00 влітку, або планувати із запасом 04:00 UTC).
6. Для спільного живого набору користуватися API/базою, а не записом JSON у локальну файлову систему Netlify Function: функції не створюють постійну зміну опублікованого сайту.

## Як перевірити пакет
- `public/index.html` — мобільний інтерфейс.
- `public/data/market.json` — історична база для загального відображення.
- `netlify.toml`, `netlify/functions/health.mjs` — заготовка для Git-based deploy та перевірки серверних функцій.
- Ні в HTML, ні в конфігурації немає приватних токенів.

## Примітки щодо достовірності
Цей реліз містить історичні записи з попереднього прототипу та позначки невизначеності; відсутні 12-місячні місцеві ряди не заповнювалися штучно. Візуальні барометри, які не можна обчислити, показують відсутність даних. Неточні базиси, класи та ПДВ мають уточнюватися до використання для рішення.
