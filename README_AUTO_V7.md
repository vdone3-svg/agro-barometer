# AGRO BAROMETER Auto V7 — логістика від Олександрії

Це обережний сценарний калькулятор, **не автоматична оцінка відстаней чи тарифів**. Він бере очищені гривневі зернові оголошення з наявного `public-indicators`, виключає архівні старші 30 днів, просить ввести перевірену відстань (км) та фактичний тариф у грн/(т·км). Якщо значення не введені — нічого не рахує.

Умовний розрахунок: витрати = км × тариф; залишок = ціна оголошення − витрати. Важливе припущення, **не підтверджене для E-ZERNO**: оголошену ціну подано за тонну. До підтвердження одиниці, ПДВ, базису та інших витрат **не називати результат чистою ціною чи рейтингом покупців**. Розрахунок не впливає на барометри 0–100.

## Встановлення
1. Розпакувати ZIP, завантажити **вміст**, а не папку, до кореня GitHub `vdone3-svg/agro-barometer` (main). Збережіть `public/` і `netlify/` у корені.
2. Netlify автоматично опублікує оновлення; **Run now не потрібен**.
3. Відкрити головну сторінку та прокрутити до «Логістика від Олександрії — Auto V7».
4. Обрати товар, компанію, ввести перевірені км і тариф — оцінити умовний сценарій.

Курси НБУ, збір E-ZERNO, Enkorr та історія V6.2 залишені без змін. Дані з сайтів не доповнювалися вигаданими логістичними показниками.
