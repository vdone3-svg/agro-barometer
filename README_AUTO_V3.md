# AGRO BAROMETER Auto V3 — непідтверджені пропозиції

1. Розпакуйте ZIP і завантажте **вміст папки** до GitHub `vdone3-svg/agro-barometer` у `main`, замінивши наявні файли. Не завантажуйте ZIP як один файл.
2. Перевірте автоматичний Deploy у Netlify.
3. У Cloud compute → Functions → collect-morning натисніть **Run now**.
4. Відкрийте `/.netlify/functions/public-indicators`: масив `sources[].data.offers` показує лише **непідтверджених кандидатів**.
5. На головній сторінці внизу з'явиться таблиця з позначкою «Не підтверджено». Якщо список порожній, на цьому етапі це безпечніше, ніж вигадувати чи змішувати ціни.

## Обмеження
- Парсер E-ZERNO експериментальний, протестований локальними прикладами, але реальна структура HTML може відрізнятися. Перший результат обов'язково перевірити.
- Записи з відносними датами «сьогодні»/«вчора» не імпортуються як ціни.
- Дані E-ZERNO не використовуються у барометрах 0–100.
- ПДВ, валюта без маркера, базис і доставка до Олександрії не підтверджені.
- Показані лише відомості з відкритого каталогу. Якщо на сайті публікуватимуться приватні умови, налаштувати авторизацію перед їх додаванням.
- Існуючі НБУ, Enkorr та графік Netlify залишено без зміни.
