# AGRO BAROMETER Auto V6.1 — контроль якості

1. Розпакуйте ZIP. Завантажте всі файли з кореня до GitHub `vdone3-svg/agro-barometer` у гілку `main`; не створюйте новий сайт.
2. Після успішного Deploy у Netlify запустіть `collect-morning` один раз.
3. Перевірте `/.netlify/functions/public-indicators`: у кожному E-ZERNO розділі з’явиться `quality_control`; пропозиції містять `freshness`.
4. Перевірте `/.netlify/functions/offer-history`: поле `quality_control.hidden_legacy_malformed` показує, скільки старих явно пошкоджених спостережень приховано з відповіді API. Вони не видаляються зі сховища.

**Обмеження.** Лічильник реально відхилених при парсингу HTML оголошень не реалізований у цій версії, щоб не видавати здогад за факт. `crop_coverage` — лише кількість пропозицій-кандидатів після перевірок; не кількість покупців. ПДВ, одиниці виміру, базис та доставку не підтверджено. Для барометрів 0–100 дані не використовуються. Старі збережені спостереження залишаються в Blobs. Захист від паралельного запису ще не реалізований.
